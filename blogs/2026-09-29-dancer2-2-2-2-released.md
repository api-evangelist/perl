(yes, that's a lot of twos!) Dancer2 2.2.2 is now headed to CPAN . This is a small bug fix release. Bug Fixes Fixed a crash when using class-method serializers ( GH #1837 ) Fixed test failures in gen.t affecting CPAN Testers and Debian builds ( GH #1843 ) Documentation Updated a contributor's name in the documentation ( PR #1844 ) There are no security fixes, enhancements, or deprecations in this release.
