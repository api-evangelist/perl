Perl is a highly capable, feature-rich programming language with over 37 years of development. It is best known for text processing, system administration, web development, and rapid scripting, supported by the Comprehensive Perl Archive Network (CPAN) with more than 25,000 open source extension modules and a global community of developers, blogs, and local user groups. The Perl Foundation supports ongoing development of Perl and its sister language Raku.
